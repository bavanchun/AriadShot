# AriadShot

AriadShot is a cross-platform (Linux and macOS) screenshot, annotation and screen-recording tool that aims to
reproduce the features, look and feel of [MacShot](https://github.com/sw33tLie/macshot) as faithfully as possible,
built with C++20 and Qt 6. It is free software licensed under the GNU General Public License, version 3 only
(GPL-3.0-only). The project is in its foundation stage; there is no usable release yet.
